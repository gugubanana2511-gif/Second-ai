# English Reading Trainer（英語リーディング学習アプリ）

英語の文章を入力すると、**日本語訳**と**読み上げ（Text-to-Speech）**で学習できる、ブラウザだけで動くシンプルな英語学習アプリです。

## 主な機能

- **日本語訳**: 入力した英文全体、および一文ごとの日本語訳を表示
- **読み上げ**: ブラウザの音声合成機能（Web Speech API）で英文を読み上げ
- **速度調整**: 0.5x〜1.75x のスライダー＋「超ゆっくり／ゆっくり／標準／速め」のプリセットボタン
- **US / UK 発音切り替え**: アメリカ英語・イギリス英語（端末に対応音声があればオーストラリア英語なども）を選択可能。同一端末に複数の音声がある場合は個別に選択も可能
- **音の高さ調整**: ピッチスライダー
- **一文ずつ再生**: 長文を一文ごとに分割して個別に再生・和訳確認ができる（シャドーイング練習向け）
- **リピート再生（シャドーイングモード）**: 同じ文章を繰り返し再生
- **読み上げ中のハイライト表示**: 発音中の単語をハイライト表示（対応ブラウザのみ）
- **マイフレーズ帳**: 気になった文章をブラウザに保存し、後から読み込み・再生・削除が可能（`localStorage` に保存、サーバー送信なし）
- **学習のヒント**: シャドーイングのやり方など、効果的な学習方法を案内

## 使い方

このアプリはビルド不要の静的サイトです。`index.html` を直接ブラウザで開くか、任意の静的サーバーで配信するだけで動作します。

```bash
# 例: ローカルで簡易サーバーを立てて確認する場合
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

GitHub Pages 等の静的ホスティングにもそのままデプロイできます。

## 動作環境

- 読み上げ機能は各ブラウザの **Web Speech API (`speechSynthesis`)** を利用します。Google Chrome または Microsoft Edge を推奨します（Safari / Firefox でも動作しますが、対応する音声の種類が異なります）。
- 選択できる音声（US / UK など）は、利用しているOS・ブラウザにインストールされている音声エンジンに依存します。

## 翻訳について

翻訳には Google 翻訳の簡易エンドポイントを利用しています。これは非公式なものであり、APIキーを必要としない反面、利用量やレスポンス仕様が予告なく変更・制限される可能性があります。あくまで学習の参考用としてご利用ください。
